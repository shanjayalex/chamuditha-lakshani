# Posters

Each poster needs two files:

| File | Size |
|---|---|
| `name.jpg` | full size, max 1350 px tall (4:5 = 1080×1350, 1:1 = 1080×1080, 9:16 = 760×1350) |
| `name-560.jpg` | 560 px wide grid thumbnail |

Keep files under about 250 KB each. Then register the poster in `src/data/content.js`. See the main README, under "Add a poster".
